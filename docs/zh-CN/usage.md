# 日常使用

这一页讲连上 host 之后怎么用桌面客户端。还没装好的话，先看 [安装上手](install.md)。碰到连不上、一直排队这类问题，见 [常见问题](faq.md)。名词解释见 [概念](concepts.md)。

界面默认是英文，在「设置 → 通用 → Language / 语言」里可以换成中文。下面引用的界面文字都按中文界面写。

> 截图待补：桌面客户端主界面，左边是会话列表，右边是一个群的对话。

## 界面是怎么排的

- **左边是会话列表**：群和私聊排在一起，最近有动静的在上面。每行有头像、名字、时间和一行预览，有未读时时间下面有一个小圆点。列表顶部右边的圆形「+」用来引入新 bro。
- **列表底部**：一个「搜索」框，按名字或预览筛选会话；它上面是你自己的那一行，点开有「设置」和「在这台设备上退出」。
- **右边是当前打开的对话**：顶栏左边是头像、名字（私聊会标「私聊」），右边是「•••」菜单；中间是消息气泡和卡片；底下是输入框。
- 窗口比较窄（不到 760 像素宽）时，列表和对话各占一整屏：点进去看对话，点左上角的「‹」返回，旁边的数字是其他会话的未读数。

以前列表下面那排「例行任务」「记忆」「技能」「联网搜索」「MCP」按钮已经收进「设置」页，见下面的 [客户端有哪些页面](#客户端有哪些页面)。

## 引入一个 bro，和它私聊

点列表顶部的「+」，在「引入一个 bro」页给它起个名字、选个头像（都可以不填），点「引入」。host 会新建这个 bro，并打开你和它的私聊。不填名字时默认叫 `bro`，已经有了就叫 `bro 2`、`bro 3`，以此类推。

在私聊里直接写，回车发送。不用 `@`，话会派给这个 bro。输入框的提示是「发给 某某…」。

你引入的 bro 归你所有。改名、改头像都在私聊里做：「•••」里的「查看资料」打开它的头像页，可以选形状和颜色，或者「用默认头像」。同一个 bro 在所有群里都用同一个名字和头像。

## 在群里说话

客户端里还没有「建群」和「把 bro 拉进群」的按钮，要先用 host 的接口建好，见 [安装上手](install.md#想要一个有多个-bro-的群)。建好的群会出现在列表里。

群里的输入框提示是「发消息，@名字 派活」。

- **以 `@名字` 开头**（全角 `＠` 也行），例如 `@ada 写一句欢迎语`：这个 bro 先接活。名字必须是群里的 bro，后面要跟空格或直接结束；只写 `@ada`、没有正文，不会派任务。群里其他 bro 随后也会轮到一次，可以插话，也可以不出声，不出声就什么都不显示。
- **没 @ 任何 bro**：只有一个 bro 回。host 按这个顺序挑：正在和你办事的那个（手上有没做完的任务，或有一张你还没答的选项卡）；群里只有一个 bro 时就是它；否则让模型按名字和资料挑一个；再不行就是上次回话的、或最早进群的那个。想恢复成以前那样每个 bro 都回一遍，给 host 设 `ROBROZ_SINGLE_RESPONDER=0`，见 [配置](configuration.md#其他常用的-host-变量)。
- **bro 回话之后**，群里其他 bro 还会再轮一两次，看要不要接着说；bro 的回复以 `@名字` 开头时，被点到的那个先说。最多两轮就停。

### 追加：给正在干活的 bro 补一句

如果点到的 bro 在这个群里已经有一个没做完的任务（排队、进行中或卡住），你这句话不会另开一个任务，而是追加到那个任务上，让它带着这句补充接着做。私聊里也一样，不用 `@`。

## 任务开始之后，你会看到什么

你发的话出现在右边。bro 那边会有一张这个任务的状态卡，同一张卡就地更新，不会一张接一张地堆出来。卡上有一个小圆点和一句状态：

- **排队**（灰色）：已经收下，还没开始跑。
- **进行中**：容器正在跑。bro 正在做的事会写在下面一行浅灰小字里，比如「在想怎么回」「在沙箱里跑」「在用 某某工具」；任务被拆成几步时，旁边会显示「第 2/3 步」。列表预览也会换成这句。
- **完成**（绿色）：做完了。卡上带这次用了多长时间。
- **等你批准**（灰色）：旁边有一张审批卡等你答，这张状态卡本身没有按钮。见 [权限和审批](permissions.md)。
- **卡住**（琥珀色）：需要你去私聊接手，比如要填验证码。卡上有「去私聊接管」，这颗按钮目前还没接上，见 [常见问题](faq.md#点了去私聊接管没有反应)。
- **没做成：原因**（灰色）：任务已经结束，但活没做成。见 [权限和审批](permissions.md#任务结束了但活没做成)。
- **没写出结果**（灰色）：跑过，但没交出结果。不会自动再跑。

任务的计时从这一轮真正开始运行时算起，断线重连之后也是准的。

输入框上方会显示谁正在处理；每个 bro 的中间过程折叠成一行，做完后显示「用了 某某时间」。

做完并写出结果时，还有一张交付卡：一句摘要，加一行结果文件在群目录里的路径，只显示，点不开。例行任务跑出来的结果，角上标「简报」。这次本想联网搜索但还没设置时，卡上有「去设置」，路径下面一行灰字「这次没联网搜索：还没设置」。

对话里还可能出现：

- **选项卡**：在两到四个固定选项里选，可以单选或多选，其中一项可能是 bro 的推荐。只能答一次。
- **审批卡**：做一件需要你点头的事之前问你，按钮是「批准」「拒绝」。见 [权限和审批](permissions.md)。
- **确认卡**：bro 想记下一条记忆或收下一项技能。见 [记忆和技能](memory-and-skills.md)。

图片和文件消息目前只显示一行带标签的名字，没有查看器。

## 群的菜单和群资料

对话顶栏右边的「•••」：

- **查看资料**：打开群资料页，有群名、成员数和这个群里开着几个例行任务。
- **在聊天里找**：在这个群的消息里搜关键词，中文也能搜。
- **改名**、**成员**、**删除群**：只在群里有，私聊里没有。「成员」列出群里的 bro。删群前会再问一次：聊天记录、任务和例行任务会删掉，正在跑的任务会停掉，bro 不会删。

## 未读

每个会话记一个「看到哪里」。计入未读的，只有 bro 发来、需要你看的东西：交付卡、选项卡、审批卡、确认卡，以及变成要你处理的任务。你自己说的话，以及排队、进行中、完成这些过程变化，不算未读。打开一个会话就会标成已读。

群里的审批卡在群里答；同时你和这个 bro 的私聊里会多一行提醒「某某 在 某群 等你审批」，点它就跳到群里那张卡。这行提醒也算一条未读。

## 例行任务

「设置 → bro → 例行任务」，或群资料页里的「例行任务」，能看到各群里已经设好的定时任务，并能暂停或恢复，暂停了的标「已暂停」。暂停只阻止下一次再开跑，已经排上队或正在跑的不受影响。到点跑成功时，交付卡角上标「简报」。

时间按 UTC 计算，错过的次数不会补跑。客户端里目前只能查看、暂停和恢复；新建例行任务要用 host 的 `POST /api/schedules` 接口，见 [api.md](../api.md#routines-schedules)。空列表上那句「在群里对 bro 说『每天 8 点给我发简报』就会出现在这里」是以后的用法，现在这样说并不会建出例行任务。

## 客户端有哪些页面

「设置」页分三组：

| 组 | 里面有 |
| --- | --- |
| 通用 | Language / 语言、外观（跟随系统、浅色、深色） |
| bro | 模型、联网搜索、MCP、技能、记忆、例行任务、放行规则 |
| 连接 | 地址（host 地址和令牌） |

最下面是「在这台设备上退出」和版本号。

- **模型**：接哪套模型，见 [配置](configuration.md#接上模型)
- **联网搜索**、**MCP**：见 [搜索和 MCP](search-and-mcp.md)
- **技能**、**记忆**：见 [记忆和技能](memory-and-skills.md)
- **例行任务**：见上面
- **放行规则**：让自动审核替你批准某些操作，见 [权限和审批](permissions.md#放行规则和自动审核)

## 手机端

手机端（Slint）是 v0.2 的试验版，能连 host、看会话列表、在会话里聊天和看状态卡。和桌面端的区别：

- 设置里只有语言、外观、MCP（只读）和「在这台设备上退出」。技能、例行任务、记忆、模型、联网搜索和放行规则只在桌面端。
- 审批卡在手机上只读：显示「等你批准：某某」和「到桌面上批准或拒绝」，没有按钮，要回到桌面端去答。

## 断线和重连

客户端和 host 之间是实时推送。断线后会悄悄重连，连续失败超过 30 秒才在顶栏显示「正在重新连接」。重连时会把断开期间的卡片补上；如果断得太久，会重新拉一遍整个会话，这时顶栏可能短暂显示「同步中…」。host 上同时打开的连接太多时，会显示「连接太多了，稍后自动重试」。
