# 概念

下面这些词在 robroz 里经常出现，这里用人话说明它们是什么。怎么操作见 [日常使用](usage.md)，权限相关见 [权限和审批](permissions.md)。字段的精确定义见英文 [concepts.md](../concepts.md) 和 [api.md](../api.md)。

## 角色和会话

**bro**  
一个 agent。在界面上，新建叫做「引入一个 bro」。它在代码和接口里仍叫 bot（`botId`、`botName`），但对使用的人来说，叫 bro 即可。

**默认名**  
引入时不填名字，就自动起一个：第一个叫 `bro`，之后是 `bro 2`、`bro 3`，取还没被占用的那个。随时可以改。同一个 bro 在所有群里都是同一个名字。

**头像**  
可选。从一组形状和颜色里各挑一个；不选时，客户端按 bro 的 id 给一个默认的。

**你和你的 bro**  
v0.2.0 的 host 只有一个令牌，带着它连上来的就是管理员 `local-admin`，也就是你。你引入的 bro 都归你：改名、换头像、拉进群、批它的审批卡，都由你来做。从 v0.1 升级上来的旧 bro 也归 `local-admin`。v0.3 计划加多用户账号，到时群、bro 和任务按用户隔离。

**群**  
一个会话，里面有你，也可以有多个 bro。

**私聊**  
只有你和一个 bro 的群，并不是另一种东西。消息、任务、未读，都和普通群一样用。界面上会标「私聊」。私聊不能改名或删除，它的名字跟着 bro 走。

**宿主机（host）**  
跑在你机器上的后台服务，负责存数据、派任务、调模型和对外联网。

**执行器（runner）**  
每个任务在一个 Docker 容器里跑，容器里就是执行器。容器不联网，也看不到模型密钥。任务结束后容器会删掉，群目录里的文件还在。

**群目录**  
每个群在 host 上有一个文件夹，任务写出的结果也在这里。容器运行时能读写这个目录。删群时这个文件夹也一起删掉。

## 任务在干什么

一个任务只会处于下面四种状态之一，以后也不会再加：

- **排队**：已经收下，还等着开跑
- **进行中**：容器正在跑
- **卡住**：要等你处理（去批准，或去接手）
- **完成**：已经结束

「没做成」和「没写出结果」不是新的状态，而是「完成」的一种结局：任务已经结束，但带着原因。

- **没写出结果**：跑过，但没有交出结果，比如容器非正常退出、中途消失，或一步跑太久被取消。灰色，没有按钮，不会自动再跑。
- **没做成**：已经结束，但活没做成，灰色，并写上原因。见 [权限和审批](permissions.md#任务结束了但活没做成)。

**进度**  
任务正在进行时，状态卡下面那行浅灰小字，说明它正在做什么，例如「在想怎么回」「在沙箱里跑」「在用 某某工具」「第 2/3 步」。长时间没动静时，也可能显示「N 分钟没有新进度」这样的提示。列表预览也会用这句。

**计时**  
状态卡上显示这一轮用了多久，从任务这一轮真正开始运行时算起。等审批的时间也算在里面。

**追加**  
给手上还有没做完任务的 bro 再说一句，这句会追加到那个任务上，不另开新任务。

**例行任务**  
到点由 host 自动派出的普通任务。时间按 UTC 计算。成功时的交付卡角上会标「简报」。

**放行规则**  
你写下的几句话，让自动审核可以替你批准某些有风险的操作，不用每次都出审批卡。见 [权限和审批](permissions.md#放行规则和自动审核)。

## 对话里的卡片

**状态卡**  
一个任务一张，就地更新。显示 bro 现在的状态、进度和计时。

**交付卡**  
结果已经写好。上面是一句摘要，下面是结果文件在群目录里的相对路径，只显示，点不开。例行任务的交付卡角上有「简报」。

**选项卡**  
在两到四个固定选项里选，可以单选或多选。只能答一次。

**审批卡**  
做一件需要你点头的事之前问你，按钮是「批准」和「拒绝」。卡出在哪个会话就留在哪个会话；群里的卡在你和这个 bro 的私聊里还有一行提醒。默认 24 小时没人答就过期。

**确认卡**  
bro 提议记下一条记忆或收下一项技能，按钮是「记下 / 不用」或「保存 / 不用」。见 [记忆和技能](memory-and-skills.md)。

卡片再有变化时，是同一张就地替换，不会另外再出一张。

## 未读

每个会话记一个「看到哪里」。计入未读的，只有 bro 发来、需要你看的东西：交付、选项、审批、确认，以及变成要你处理的任务；群里审批卡在私聊里的那行提醒也算。你自己说的话，以及排队、进行中、完成这些过程变化，不算未读。被自动审核直接放行的审批、放行规则页上的确认卡，也不算。
