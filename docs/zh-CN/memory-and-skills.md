# 记忆和技能

记忆是 bro 记下的、关于你的事。技能是它会的一种做法。两者都只是在接了模型时，被写进给模型的说明里，不会因此多出任何权限。bro 能做什么，仍然只由 [权限和审批](permissions.md) 里的三档决定。字段和接口的精确说明见 [docs/memory-and-skills.md](../memory-and-skills.md)。

没有接模型时，记忆和技能不会被用上。

「记忆」和「技能」两个页面只在桌面客户端里有，手机端还没有。对话里的确认卡在手机上也只能看。

## 记忆是什么

一条记忆有类型、范围和正文：

- 类型有三种：资料（你是谁）、习惯（你的工作习惯）、项目（和某个项目有关的记录）
- 范围要么是「所有 bro」都能用，要么「只给」某一个 bro
- 一条正文最多 2000 个字

你自己在「记忆」页里写下的，当场生效。bro 提议的，要先经过你确认。

## 技能是什么

一项技能有一个英文短名、一个标题和一段说明：

- 短名是它的身份，只能用小写字母、数字和连字符，不能以连字符开头或结尾，最多 64 个字符，建好以后不能改
- 标题最多 80 个字，说明最多 8000 个字
- 范围和记忆一样：所有 bro，或只给某一个

你自己加的当场保存；bro 提议的也要先确认。保存之后，还要在具体的群里打开开关，这个群里的任务才会用到它。

## bro 怎样提议，你怎样确认

bro 不能直接把记忆或技能写进库里。任务顺利做完之后，它的提议会变成对话里的确认卡。任务没做完、卡住了，或者带着「没做成」，它这次提的都不收。一个任务最多收 20 条提议；和已有的重复的会跳过。

**记忆卡**左上角有「记忆」标签，下面是完整原文，再一行范围（「所有 bro」或「只给 某某」）。按钮是「记下」和「不用」。

**技能卡**左上角有「技能」标签，显示标题和短名，说明默认只露出前三行，可以「展开」看全部、「收起」折回去，下面也有一行范围。按钮是「保存」和「不用」。点了「保存」只是收下这项技能，还要到「技能」页里打开对应群的开关，才会真正用上。

同一个任务一次提了不少条时，前 3 张直接摊开，从第 4 张起收成「还有 N 条待确认」，点开再逐条确认。

确认过的卡会换成「记下了」「保存了」或灰色的「不用了」，后面跟着谁答的和时间。点了「不用」的那一条会留下来，但不会进给模型的说明，bro 也不会再提同一条。每张卡只能答一次。确认卡不会过期。

## 「记忆」页

在「设置 → bro → 记忆」打开。条目按范围分组：「所有 bro」排在最前，后面每个 bro 一组（「只给 某某」）。每组里「待确认」和「已记下」分开放。每条能看到原文、类型（资料、习惯、项目）和更新时间。一条也没有时，显示「还没有记下任何东西」。

待确认的条目可以直接「记下」或「不用」，和对话里那张确认卡是同一件事，一边答了另一边会跟着变。已经记下的可以「改」或「忘掉」。忘掉前会再问一次「忘掉这条？bro 以后不会再用到它。」，忘掉后它从列表里消失；如果当时还在待确认，对话里的卡会变成「不用了」。

要自己「记一条」，先选范围：没选时那一行写着「选一下谁能用这条」，选好后变成「只给 某某 用」或「所有 bro 都能用」。没写内容、没改动、超过 2000 字或还没选范围时，「保存」是灰的。保存成功后标「已保存」；失败则在原地提示「没保存：原因」，你写的内容还在。

## 「技能」页

在「设置 → bro → 技能」打开，结构和记忆页一样。每组里是「待确认」和「已保存」。每条能看到标题、短名和说明的前三行。一条也没有时，显示「还没有保存任何技能」。

待确认的条目是「保存」和「不用」。已经保存的可以「改」标题和说明（短名不能改），或「删除」，删除前会再问一次。下面还有「在这些群里用」，每个群一个开关。打开页面时会先去读各群的实际状态：还在读时开关是灰的，旁边写「读取中」；读失败则写「读不到」，也点不了。

「加一项」要填英文短名、标题、说明，并选范围，规则和记忆页的「记一条」一样。

## 交给模型时，能带多少

接了模型之后，host 会把仍然有效、而且这个任务用得上的记忆和技能，写进给模型的说明里：

- 只用已经确认收下的；待确认、点了「不用」和忘掉的都不会进去
- 范围是「所有 bro」或正好是干这个活的 bro
- 技能还要已经在这个群里启用
- 记忆整段最多约 4000 个字，技能整段最多约 8000 个字。超出时从最旧的整条去掉，不会把某一条截成半截
- 一条都没有时，就不会多出这一段

所以记得很多也没关系，真正带给模型的是最近、仍有效、且这个群用得上的那一部分。
